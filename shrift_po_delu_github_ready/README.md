# Шрифт по делу — проект для VS Code

Это перенос экспорта текущей страницы Tilda, а не версия старого макета Figma.

## Запуск
1. Откройте папку `shrift_po_delu_vscode` в VS Code.
2. Установите расширение **Live Server**, нажмите правой кнопкой на `index.html` и выберите **Open with Live Server**.
3. Проверьте вид на экранах шириной 1440 px, 768 px, 390 px и 320 px. В Chrome DevTools — Toggle device toolbar.

## Публикация на GitHub Pages
1. Создайте репозиторий, загрузите **содержимое папки** в корень репозитория (файл `index.html` должен находиться в корне).
2. GitHub → Settings → Pages → Deploy from a branch → main / (root) → Save.
3. Проверьте все изображения и взаимодействия на опубликованном URL.
4. Обновите 8 UTM-ссылок в Дзене на новый URL GitHub Pages.

## Важно
- Сохранён исходный HTML/CSS/JS экспорта, включая адаптивные стили, hover и click-обработчики. `index.html` — копия исходной страницы, предназначенная для GitHub Pages.
- Некоторые скрипты Tilda и Google Fonts могут использовать внешние ресурсы. Экспорт не равнозначен независимой переписанной версии; потребуется проверка после публикации.
- Яндекс Метрика: добавьте код вашего счётчика №113879376 в `<head>` `index.html` после окончательного выбора домена. Сначала проверьте, что установлен только желаемый счётчик.
- Для нового URL UTM-метки должны иметь разные `utm_content=post_01` ... `post_08`.
