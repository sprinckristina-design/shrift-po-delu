# Шрифт по делу

Образовательный лонгрид о выборе шрифтов.

## Исходники
Проект подготовлен на основе экспорта Tilda с десктопной и мобильной вёрсткой, CSS, JavaScript и изображениями.

## Как загрузить готовый проект
1. Распаковать архив `shrift_po_delu_github_ready.zip` на компьютере.
2. Открыть репозиторий GitHub и выбрать **Add file → Upload files**.
3. Перетащить **содержимое распакованной папки**, включая `index.html`, `css`, `js`, `images`, а не ZIP-файл.
4. Нажать **Commit changes**.
5. Перейти в **Settings → Pages → Build and deployment**, выбрать **Deploy from a branch**, `main` и `/(root)`.

После публикации проверить изображение, поведение кнопок и адаптивность на мобильном и десктопе, поскольку некоторые библиотеки экспорта Tilda могут обращаться к внешним сервисам.
