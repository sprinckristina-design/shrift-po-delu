# Шрифт по делу

Образовательный лонгрид о выборе шрифтов.

## Готовый лонгрид

[Открыть опубликованный лонгрид «Шрифт по делу»](https://sprinckristina-design.github.io/shrift-po-delu/?utm_source=dzen&utm_medium=article&utm_campaign=shrift_po_delu&utm_content=post_08)

## Исходники
Проект подготовлен на основе экспорта Tilda с десктопной и мобильной вёрсткой, CSS, JavaScript и изображениями.

## Использование искусственного интеллекта

При работе над проектом использовались инструменты искусственного интеллекта для помощи в разработке структуры лонгрида и написании кода сайта. ИИ выступал вспомогательным инструментом при реализации проекта.
